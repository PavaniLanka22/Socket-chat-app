**💬 Real-Time Socket.IO Chat Application**
A modern real-time chat application developed using React.js, Node.js, Express.js, and Socket.IO. The application enables multiple users to communicate instantly through WebSockets with support for room-based messaging, live typing indicators, and a responsive commercial-style user interface.


**🚀 Sprint Highlights**
🔹 Real-time bidirectional messaging using Socket.IO
🔹 Session identification with unique usernames before joining
🔹 Live typing indicator similar to modern messaging applications
🔹 Room-based communication with isolated message routing
🔹 Two independent chat channels: General, Tech Support
🔹 Responsive SaaS-inspired user interface
🔹 WhatsApp-style left/right aligned chat bubbles
🔹 Modern glassmorphism-inspired design
🔹 Clean and intuitive user experience


**🛠️ Tech Stack**: Frontend, React.js, Vite, Socket.IO Client, HTML5, CSS3, Backend, Node.js, Express.js, Socket.IO, CORS.


**✨ Features**
✅ Real-Time Messaging
Messages are instantly delivered to all users connected to the same room without refreshing the page.

✅ Session Identification
Users enter a unique username before joining the chat, and every message is displayed with the sender's identity.

✅ Typing Indicator
Displays a live "User is typing..." notification while another participant is composing a message.

✅ Room-Based Communication
Supports multiple chat rooms including: General, Tech Support.
Messages are routed only to users within the selected room, preventing global broadcasting.

✅ Responsive UI
The application provides a modern, responsive interface with:
Glassmorphism-inspired layout
Responsive design
Chat bubbles
Smooth user experience
